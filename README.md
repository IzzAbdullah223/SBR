#Smart Bus Route Planner — Dubai RTA

A full-stack web application that helps users find the best bus routes in Dubai. Uses the **TOPSIS multi-criteria decision-making algorithm** to rank routes based on travel time, cost, walking distance, and transfers — weighted by what matters most to the user.

Built as a **Final Year Capstone Project** for the Bachelor of Software Engineering.


 🌐 Live Demo

**[Click here to open the app →](https://sbr-delta.vercel.app/)**


# Features

- **Interactive map** with real Dubai RTA bus route shapes (GTFS data)
-  **TOPSIS ranking** — 4 modes: Fastest, Cheapest, Less Walking, Fewest Transfers
-  **LocationIQ autocomplete** — search any Dubai address in Arabic or English
-  **Saved journeys** — pin frequent trips for one-tap access
-  **Favorite bus stops** — save stops directly from the map
-  **Nol Card virtual wallet** — simulated balance and top-up
-  **Dark / light mode**
-  **Bilingual** — full Arabic RTL support

---

 #Tech Stack

**Frontend:** React 19, Vite, Leaflet, i18next  
**Backend:** Node.js, Express, MongoDB, Passport.js, JWT  
**Deployed on:** Vercel + Render + MongoDB Atlas
